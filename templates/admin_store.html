M-PESA listener bridge

API gateway & live receipt stream

Point the phone/listener app here. Every receipt is stored before matching, so unmatched messages are not lost.

Use this exact URL in the listener app. The /api/gateway/messages alias points to the same receiver.
{% if store_settings.gateway_secret %}A gateway secret is already configured. Leave this blank unless you want to replace it.{% else %}No gateway secret is configured yet. Set the same secret in the listener app.{% endif %} Listener may send X-Toror-Gateway-Key or Authorization: Bearer <secret>.
Receipt must be for a pending order created within this window; name, phone and amount must still match exactly.
Listener payload

What the listening app should send

POST {{ gateway_url }}
X-Toror-Gateway-Key: YOUR_SECRET
Content-Type: application/json

{
  "gateway_id": "DENMART-GW-...",
  "sim_device": "SIM 1",
  "sender": "M-PESA",
  "received_at": "2026-10-07T12:05:00+00:00",
  "payer_name": "JOHN DOE",
  "payer_phone": "254712345678",
  "amount": 1000,
  "transaction_code": "UJ40P8ABCD",
  "raw_message": "Full M-PESA SMS text here",
  "delivery": "RECEIVED"
}

The receiver also accepts flexible JSON/form field names and can extract amount, payer phone, payer name and transaction code from a normal M-PESA receipt when structured fields are missing.
